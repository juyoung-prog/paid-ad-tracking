# Beauty Master Design System

An internal design system and UI development environment for Beauty Master.

This project provides reusable UI components, design patterns, and development guidelines to help maintain consistency across digital products.

---

## Overview

The project provides a shared environment where designers and developers can build, review, and test UI components.

The system is built around reusable components and documented UI patterns so that new interfaces can be created consistently and efficiently.

---

## Tech Stack

### React

React is used as the component-based UI framework for building reusable interface components.

### Material UI (MUI)

Material UI provides the foundation for common UI components and interaction patterns.

Components can be customized to match Beauty Master's visual and product requirements.

### Storybook

Storybook provides an isolated environment for viewing, testing, and documenting UI components.

It allows the team to review components independently from the main application.
